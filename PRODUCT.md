# Garage

## Platform and stack
Native desktop application for Linux and Windows, built with Rust/GPUI and a local Python sidecar.

## Purpose
Prepare PDFs, images, and scans without uploading documents. Includes OCR and Bikram Sambat date conversion.

## Confirmed requirements
- Local-only operations; no account, telemetry, or network-dependent processing.
- Always preserve source files and export new copies.
- Visual page organization, image/PDF conversion, watermarks, numbering, and password tools.
- Batches use shared settings with per-file overrides and continue after failures.
- Arabic and Roman page numbering.
- User requests polished controls inside tool pages while preserving the original interface and sidebar styling. PDF navigation remains grouped under one submenu.

## Users
People preparing private documents locally. More specific audience needs remain open.
