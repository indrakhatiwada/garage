# Garage interface

## Scope
Preserve the original forest-green theme, sidebar branding, window chrome, artwork, and page identity. The user explicitly rejected a sidebar/theme redesign. The only authorized navigation change is grouping PDF tools under one expandable submenu.

## Page controls
Refine controls within existing tool pages: consistent field spacing, readable labels, well-sized segmented choices, deliberate selected states, native switches and selects, and clearly separated preview/settings areas. Avoid listing possible values in field labels. Include units on choices, and explain consequences with short supporting text.

## Tokens
Use the existing theme tokens for every surface, text, border, and state. Do not introduce a new palette. Use native 36px selects for discrete settings, an opacity slider with a percentage readout, aligned switches for booleans, and labeled inputs for numbers and text. Segmented tabs are reserved for switching workflows or preview modes. All upload surfaces use the shared 240px dropzone, identical artwork and browse affordance; only accepted-file guidance varies. Compression defaults to copies beside the source files; choosing an output folder is optional.
